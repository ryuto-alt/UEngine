# LE4Game Engine 機能一覧

## 概要
LE4Game Engineは、DirectX 12をベースとした3Dゲームエンジンです。
C++で実装されており、モダンなグラフィックス機能と物理演算、アニメーション、オーディオなど、
ゲーム開発に必要な包括的な機能を提供します。

---

## コアシステム

### Framework（フレームワーク）
- **ゲームループ管理**: 初期化、更新、描画、終了処理の統合管理
- **シーン管理**: シーンの切り替えと管理
- **汎用的な基底クラス**: カスタムゲームロジックの継承実装

### DirectXCommon（DirectX12基盤）
- **DirectX12初期化**: デバイス、コマンドキュー、スワップチェーンの初期化
- **描画パイプライン**: 描画前処理・後処理の管理
- **シェーダーコンパイル**: DXCを使用した動的シェーダーコンパイル
- **リソース管理**: バッファ・テクスチャリソースの作成と管理
- **デスクリプタヒープ管理**: RTV、DSV、SRVのデスクリプタ管理
- **フルスクリーン切り替え**: ウィンドウ/フルスクリーンモードの切り替え
- **動的リサイズ**: ウィンドウサイズ変更時のバッファ再作成
- **FPS制御**: フレームレート固定機能
- **ImGui統合**: デバッグUI（デバッグビルド時）

### Scene Management（シーン管理）
- **SceneLoader**: JSONファイルからのシーン読み込み
- **SceneConfigurator**: シーン設定の構成と適用
- **動的シーン生成**: オブジェクト、カメラ、エネミーなどの自動生成

---

## グラフィックス

### レンダリング基盤
- **Model**: 3Dモデルの読み込みと管理
- **Object3d**: 3Dオブジェクトの配置、トランスフォーム、描画
- **Sprite**: 2Dスプライト描画システム
- **SpriteCommon**: スプライト共通処理とテクスチャ管理

### 高度なレンダリング機能
- **InstancedRenderer**: インスタンシング描画（最大10000インスタンス）
  - LODシステム統合（距離ベースの詳細度切り替え）
  - 大量オブジェクトの高速描画
- **LineRenderer**: デバッグ用ライン描画
- **Skybox**: キューブマップベースのスカイボックス
  - 環境マップ自動管理
  - フォグエフェクト対応
- **CullingSystem**: フラスタムカリング最適化
  - AABB、球体、点の視錐台判定
- **RenderingPipeline**: レンダリングパイプライン管理

### ポストプロセス
- **PostProcess**: ポストエフェクト処理
  - ホラーエフェクト（ノイズ、歪み、ブラッド、ビネット）
  - 魚眼レンズエフェクト
  - カスタマイズ可能なエフェクトパラメータ

### テクスチャ・リソース管理
- **TextureManager**: テクスチャの読み込みと管理
- **SRVManager**: Shader Resource Viewの管理
- **ResourcePreloader**: リソースの事前読み込み
- **TinyGLTFLoader**: GLTFフォーマットのモデル読み込み
- **JsonParser**: JSONデータの解析

### ビデオ再生
- **VideoPlayer**: 動画ファイルの再生機能
  - Media Foundation統合
  - ループ再生対応
  - 再生制御（再生、一時停止、停止）

## アニメーション

### スケルタルアニメーション
- **AnimatedModel**: ボーンアニメーション付きモデル
  - Assimpライブラリ統合
  - GLTFアニメーション対応
  - スキニング処理
- **AnimationPlayer**: アニメーション再生制御
  - ループ再生
  - 再生速度調整
- **AnimationBlender**: アニメーションブレンディング
  - スムーズなアニメーション遷移
  - ブレンド進行度管理
- **AnimationUtility**: アニメーション補間ユーティリティ
- **Animation**: アニメーションデータ構造

---

## カメラシステム

### Camera（カメラ）
- **複数カメラモード**:
  - フリーカメラ（自由移動）
  - 固定カメラ
  - オービットカメラ（プレイヤー追従）
- **入力制御**:
  - マウス視点移動（感度調整可能）
  - ゲームパッド右スティック対応
  - 視点ロック/アンロック機能
- **プロジェクション設定**: FOV、アスペクト比、クリップ距離
- **フラスタムカリング**: 視錐台判定機能
- **魚眼レンズエフェクト**: カメラレベルでのエフェクト制御
- **デバッグモード**: フリーカメラモード切り替え（デバッグビルド）

### Frustum（視錐台）
- **フラスタムカリング**: 視錐台範囲外オブジェクトの描画スキップ
- **判定機能**: 点、AABB、球体の視錐台内判定

---

## 物理・衝突判定

### Collision（コリジョン）
- **AABBCollision**: 軸平行境界ボックス（AABB）衝突判定
- **CollisionHelper**: 衝突判定補助関数
- **CollisionPrimitive**: 基本的な衝突プリミティブ定義

## ナビゲーション・AI

### NavMesh（ナビメッシュ）
- **NavMeshSystem**: ナビゲーションメッシュシステム
- **NavMeshDebugDraw**: ナビメッシュデバッグビジュアライゼーション
  - パス表示
  - エージェント表示
  - メッシュ構造表示

---

## パーティクルシステム

### 2Dパーティクル
- **ParticleManager**: 2Dパーティクル管理
- **ParticleEmitter**: 2Dパーティクルエミッター

### 3Dパーティクル
- **Particle3DManager**: 3Dパーティクル管理
  - 大量パーティクル対応
  - カラー・スケール補間
  - 重力・加速度シミュレーション
- **Particle3DEmitter**: 3Dパーティクルエミッター
- **Particle3DDemo**: パーティクルデモシステム
- **HitEffect3D**: ヒットエフェクト
- **EffectManager3D**: 3Dエフェクト管理

---

## オーディオ

### AudioManager（オーディオマネージャー）
- **XAudio2統合**: 高性能オーディオエンジン
- **フォーマット対応**:
  - WAVファイル再生
  - MP3ファイル再生（Media Foundation）
- **再生制御**: 再生、停止、一時停止、再開
- **音量制御**:
  - 個別音量調整
  - マスターボリューム
  - パンニング（左右バランス）
  - 左右独立音量設定
- **ループ再生**: シームレスループ対応

### 3D空間オーディオ
- **SpatialAudioSource**: 3D空間音源
- **SpatialAudioListener**: 3Dオーディオリスナー
- **AudioSource**: 基本オーディオソース
- **Mp3File**: MP3ファイル読み込み
- **WaveFile**: WAVEファイル読み込み

---

## 入力システム

### Input（入力管理）
- **キーボード入力**:
  - キー押下判定（PushKey）
  - キートリガー判定（TriggerKey）
- **マウス入力**:
  - マウス状態取得
  - マウス移動量取得
  - マウスカーソル表示/非表示
  - マウスボタントリガー判定
  - マウスセンタリング機能
- **ゲームパッド入力（Xbox Controller）**:
  - ボタン押下・トリガー判定
  - 左右スティック入力
  - 左右トリガー入力
  - デッドゾーン処理
  - 最大4プレイヤー対応
- **DirectInput統合**

## デバッグ機能

### デバッグビルド専用機能
- **ImGui統合**: リアルタイムパラメータ調整UI
- **リソースリーク検出**: D3D12デバッグレイヤー統合

- **LineRenderer**: デバッグ用ライン描画

---

## 特徴的な機能

### パフォーマンス最適化
- **インスタンシング描画**: 大量オブジェクトの効率的な描画
- **フラスタムカリング**: 不可視オブジェクトの描画スキップ
- **LODシステム**: 距離ベースの詳細度自動調整
- **リソースプリロード**: 事前読み込みによる遅延削減

### 柔軟なシーン構築
- **JSONベースシーン定義**: 外部ファイルからのシーン構築
- **動的オブジェクト生成**: ランタイムでのオブジェクト追加・削除
- **環境マップ自動適用**: スカイボックスから環境マップ自動設定

### エフェクト・演出
- **ホラーエフェクト**: ノイズ、歪み、ビネット、ブラッドエフェクト
- **魚眼レンズ**: 可変強度の魚眼レンズエフェクト
- **3Dパーティクル**: 大量パーティクルによる視覚効果
- **動画再生**: インゲームムービー・カットシーン対応

### マルチプラットフォーム入力
- **キーボード・マウス**: PC標準入力
- **Xbox Controller**: ゲームパッド対応
- **統合入力システム**: 複数入力デバイスの統一管理

---

## 技術スタック

- **グラフィックスAPI**: DirectX 12
- **オーディオAPI**: XAudio2, Media Foundation
- **ウィンドウシステム**: Win32 API
- **シェーダー**: HLSL (DXC Compiler)
- **プログラミング言語**: C++17以降
- **ビルドシステム**: Visual Studio 2022
- **対応プラットフォーム**: Windows 10/11

## ファイル構成

```
src/Engine/
├── Animation/      # アニメーションシステム
├── Audio/          # オーディオシステム
├── Camera/         # カメラシステム
├── Collision/      # 衝突判定
├── Core/           # コアシステム（Framework, Scene）
├── Graphics/       # グラフィックス・レンダリング
├── Input/          # 入力システム
├── Math/           # 数学ライブラリ
├── NavMesh/        # ナビゲーションメッシュ
├── Particle/       # パーティクルシステム
├── Resource/       # リソース管理
├── Scene/          # シーンローダー・管理
└── Utility/        # ユーティリティ（Logger, WinApp等）
```
